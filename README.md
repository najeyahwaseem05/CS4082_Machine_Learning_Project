## 📘 Project Phases

### Phase 1 — Literature Review
Summary of prior work, problem framing, and justification of chosen ML approaches.  
File: `MLProjectPhase1_LiteratureReview.pdf`

### Phase 2 — Data Preprocessing & EDA
- Data cleaning  
- Handling missing values  
- Feature engineering  
- Exploratory visualizations  
File: `MLProjectPhase2_DataPreprocessingandEDA.ipynb`

### Phase 3 — Baseline Models
- Logistic Regression  
- Decision Trees  
- KNN  
- Baseline performance metrics  
File: `MLProjectPhase3_BaselineModelsTraining.ipynb`

### Phase 4 — Model-Centric Improvements
- Hyperparameter tuning  
- Feature selection  
- Model optimization  
File: `MLProjectPhase4_ModelCentricImprovement.ipynb`

### Phase 5 — Evaluation & Interpretability
- Final model evaluation  
- Confusion matrices  
- SHAP / feature importance  
File: `MLProjectPhase5_Evaluation&Interpretability.ipynb`
